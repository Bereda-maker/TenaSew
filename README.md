# TenaSew (ጤናሰው)

A warm, Ethiopia-rooted wellness and body-confidence platform: **Feel better. Be yourself. Grow confidently.**

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Validate with `npm run typecheck`, `npm test`, and `npm run build`.

## Production readiness

The MVP includes the responsive product experience, content model, safe AI fallback, route manifest, starter database migration, and deployment docs. Real authentication, provider-backed persistence, rate limiting, RLS, admin mutation routes, and professional verification must be configured before collecting real user data. See `docs/DEPLOYMENT.md`, `docs/ARCHITECTURE.md`, `.env.example`, and `TODO.md`.
